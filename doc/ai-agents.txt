1. INTRODUCTION                                   *ai-agents-introduction*

ai-agents.nvim lists every AI coding agent available to you -- Claude Code,
OpenAI Codex, GitHub Copilot, opencode, Gemini CLI, and the API models
CodeCompanion supports -- in a single picker, and gives you one pair of
mappings to approve or reject the changes they propose.

Providers come in two kinds:

  ACP agent    An external CLI driven over the Agent Client Protocol. It edits
               files and you approve each change in a diff. Needs its CLI
               installed.

  HTTP model   An API provider used for chat and inline edits. Needs an API
               key.

Agents whose CLI is missing are listed last and name the binary they need.

==============================================================================
2. REQUIREMENTS                                   *ai-agents-requirements*

  - Neovim >= 0.10
  - coder/claudecode.nvim        (Claude Code)
  - olimorris/codecompanion.nvim (every other provider)

Both are declared as dependencies and configured for you, so with lazy.nvim
the whole install is:
>lua
    { "tw4/ai-agents.nvim" }
<
Nothing loads until you first use a command or mapping. To change the mappings,
override `keys` in your own spec.

3. SETUP                                                 *ai-agents-setup*

>lua
    require("ai_agents").setup({
      keymaps = true,
      prefix = "<leader>i",
      exclude = { "jina", "tavily", "duckduckgo" },
      claude = {
        resolve_cmd = true,
        cmd_candidates = { "~/.local/bin/claude", "~/.claude/local/claude" },
      },
    })
<
                                                       *ai-agents-keymaps*
keymaps ~
    Register the default mappings. Set to false to bind the commands
    yourself. Default: true

prefix ~
    Prefix for the default mappings. Default: "<leader>i"

exclude ~
    Adapters to hide from the picker. CodeCompanion ships a few that back the
    @web_search tool rather than chat, and picking one fails confusingly.

claude.resolve_cmd ~
    Resolve an absolute path to the Claude CLI. A $HOME-local install is not
    always on $PATH when Neovim starts outside a login shell, which makes
    claudecode.nvim fail with "'claude' is not executable". Default: true

claude.cmd_candidates ~
    Paths tried, in order, before falling back to `claude` on $PATH.

4. COMMANDS                                           *ai-agents-commands*

                                                                *:AiAgents*
:AiAgents           Pick a provider and open a session with it.

                                                          *:AiAgentsToggle*
:AiAgentsToggle     Hide the open session, or bring the last one back. With no
                    session opened yet, falls through to the picker.

                                                          *:AiAgentsAccept*
:AiAgentsAccept     Accept the changes an agent has proposed.

                                                            *:AiAgentsDeny*
:AiAgentsDeny       Reject the changes an agent has proposed.

==============================================================================
5. MAPPINGS                                           *ai-agents-mappings*

With the defaults:

  <leader>ip    Pick a provider
  <leader>it    Show or hide the session
  <leader>ia    Accept the proposed changes
  <leader>id    Reject the proposed changes

Accept and reject work whichever agent proposed the change, and from either
half of the diff. The two backends are resolved differently and neither knows
about the other: Claude Code answers to :ClaudeCodeDiffAccept, and only while
the cursor is in the proposed buffer -- otherwise it reports "No active diff
found in current buffer". Every ACP agent and model that CodeCompanion drives
answers instead to a keymap bound inside its own diff buffer. These mappings
find whichever of the two is on screen, move the cursor there, and resolve it.

The proposed buffer is an ordinary buffer -- edit it before accepting and your
version is what gets written.

6. HEALTH                                               *ai-agents-health*

>vim
    :checkhealth ai_agents
<
Reports which agent CLIs are installed, which are missing, and how to install
them.
